WHAT IS INSIDE
  config/options.ini ........................ graphics settings (fullscreen, texture step)
  config/pz_modlist_settings.cfg ............ mod profiles, including "Blackout Protocol" ({n} mods)
  config/modlist_blackout_protocol.txt ...... the same list, one mod per line (for checking)
  Sandbox Presets/NeoiMods Ajanlott.cfg ..... Hungarian sandbox preset
  Sandbox Presets/Neoi-Suggested.cfg ........ the same preset under an English name
  launcher/ProjectZomboid64.bat ............. the ZGC launcher (this is where the memory settings live)

MANUAL INSTALL
  1. Close the game.
  2. config/options.ini  ->  C:\Users\<user>\Zomboid\options.ini
  3. config/pz_modlist_settings.cfg  ->  C:\Users\<user>\Zomboid\Lua\pz_modlist_settings.cfg
  4. contents of Sandbox Presets  ->  C:\Users\<user>\Zomboid\Sandbox Presets\
  5. launcher/ProjectZomboid64.bat  ->  <Steam>\steamapps\common\ProjectZomboid\  (back up the old one first!)
  6. Start the game, pick the "Blackout Protocol" mod profile.
     For a new game use the sandbox preset "Neoi-Suggested" (or "NeoiMods Ajanlott" in Hungarian).

IMPORTANT
  - The game launches through ProjectZomboid64.bat, NOT the JSON. Memory settings must go there.
  - Using our launcher is recommended: it does everything for you.
  - The updated config is coming to the Steam collection soon.
